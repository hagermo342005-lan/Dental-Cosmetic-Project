# FFHQ Report

## Dataset Name
FFHQ (Flickr-Faces-HQ)

## Description
FFHQ is a high-quality human face dataset developed by NVIDIA. It contains diverse face images with different ages, genders, ethnicities, and backgrounds.

## Purpose
The dataset is used for face generation, image enhancement, image synthesis, and training deep learning models.

## Number of Images
70,000

## Image Resolution
1024 × 1024 pixels

## Image Format
PNG

## Advantages
- Very high image quality.
- Diverse facial appearances.
- Suitable for GAN and AI applications.

## Limitations
- Does not contain facial attribute labels like CelebA.
- Large storage size.
